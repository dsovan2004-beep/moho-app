# Homepage photo provenance — checked November 6, 2026

## Mountain House

Actual aerial photography from USDA NAIP’s public federal image service. Catalog tile `m_3712112_se_10_060_20240515`, OBJECTID 20291, California, acquisition May 15, 2024. Export locked to this raster; requested WGS84 bbox -121.557,37.769,-121.535,37.780; output Web Mercator 1600×1000. This covers Mountain House neighborhoods and the creek/park corridor around the city’s published coordinates (37.77389,-121.54417), not the separate historic Alameda County waystop. Location cross-check: https://en.wikipedia.org/wiki/Mountain_House,_California and city civic addresses https://www.mountainhouseca.gov/168/Contact-Us.

Source service: https://apps.geo.fpac.usda.gov/geo-imagery/rest/services/naip/conus_naip/ImageServer . USDA dataset license/public-domain statement: https://catalog.data.gov/dataset/national-agriculture-imagery-program-naip-imagery . Request parameters and catalog response preserved here. May 2024 is historical imagery, not a current or live view. The 2013 high-school construction photo was reviewed and rejected as unsuitable for a current homepage view.
